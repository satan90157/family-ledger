# 家計簿 v1.6.1：手機介面與操作修正

此版以 v1.6 為基礎，**不更改交易資料格式或 Google Apps Script 程式**。

## 修正項目

- iPhone 窄螢幕的交易明細改為卡片式，日期、店家、金額不必橫向滑動。
- 篩選結果新增合計：僅支出顯示支出總額；僅收入顯示收入總額；全部顯示收入、支出及差額。這個總額會跟搜尋、月份、分類、歸屬篩選同步更新。
- 發票有品項時可以在該交易下方展開完整品項與小計。
- 年度 12 個月趨勢圖在手機畫面內縮放，盡量避免水平捲動。
- 修正「取消編輯」錯誤回到新增頁面的問題；若已填內容，會詢問是否放棄。
- 新增或編輯儲存時顯示本機儲存提示，待雲端同步成功再顯示完成提示。

## 安裝

1. 升級前先從原網站匯出 JSON 備份，並確認 Google Sheets 同步完成。
2. **若你已部署 v1.6 的 Apps Script**，只需替換 GitHub 儲存庫根目錄的 `index.html`，後端不必重部署。
3. **若仍在使用 v1.5 的 Apps Script**，須先將此包內 `apps-script/Code.gs` 貼至既有 Apps Script 專案，並「管理部署作業 → 編輯 → 新版本 → 部署」，再替換 `index.html`。保留原 Script Properties。
4. 手機重新整理網站（包含加入主畫面的版本），測試搜尋、取消、儲存和同步。

## 未包含

- v1.7 的帳號密碼登入、使用者身分及 Audit Log。
- 年度按需載入與分頁 API（需要同步改動前後端，規劃於 v1.7）。

## 驗證狀態

JavaScript 語法檢查已通過；尚未在真實 iPhone 和 Google Sheets 上進行端到端操作測試。
