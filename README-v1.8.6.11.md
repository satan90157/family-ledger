# v1.8.6.11 交付與部署

## 檔案
- GitHub Pages：更新 `index.html`
- Google Apps Script：**更新 `Code.gs`，新增 `Planning.gs`**
- 其餘既有後端 `.gs` 檔案維持不變。
- 更新 Apps Script 部署為新版本，既有帳本不執行 setup。首次使用會建立 `PlanningData` 工作表。

## 新功能
- 預算頁：新增家庭全部視角（彙總 me / wife / shared），在此視角無法編輯原本三帳戶的基本月額。
- 可自訂理財配置項目，固定月費／年度預留／彈性預算／基金，提供 AI 建議與實際設定，備份於 Google Sheets `PlanningData`。
- 匯出 `FINANCE-ANALYSIS.json`，送 AI 分析後可匯回 `family-ledger-finance-recommendations-v1` 格式。匯入只填 AI 建議，需人工儲存，不自動覆寫實際設定。
- 年度統計：月預算 vs 實際支出對比。
- 退休規劃：新獨立頁籤、個人／家庭複利、年化報酬率動態調整、通膨及缺口試算。
- 手機 375/390px：預算項目卡片化、退休表單雙欄或單欄、圖表 SVG 自適應。

## 限制與注意
- AI 分析匯出包含交易明細，送到外部 AI 前自行檢查敏感資料。
- 初始固定金額來自先前規格討論與試算，並非全部經過 CSV 驗證。尤其資金歸屬、車貸終止時間、所得稅、車輛保險以實際帳單為準。
- 基金／預留金是「預算安排」，不是帳戶已入金或實際存款；不可直接拿安排金額當成現金餘額。
- 年度預算圖目前比對整體配置月額與實際支出，分類對照、追溯每筆預留資金尚未實作，不應視為完整資產負債對帳。
- 退休計算是假設固定年化報酬、月底投入、月複利，無稅費與波動模擬；家庭兩人不同退休年份的合併圖為相對各自退休進度之情境線。
- 更新後先用測試帳本驗證新增、編輯、跨裝置同步、跨頁年圖、退休動態輸入、AI 匯入錯誤、後端拒絕無效資料。
