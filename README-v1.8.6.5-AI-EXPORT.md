# 家計簿 v1.8.6.5 — AI 歷史整理安全匯出（開發版）

本版只改 index.html。依現有 Apps Script 的 years/list API 讀取年度交易；讀取失敗整個匯出中止。阻擋本機快速編輯草稿與 pending 未同步資料。下載 CSV（供 AI 建議）和完整 JSON（未修改的匯出基準）。交易 ID 跨年不可重複。

限制：非 XLSX；無 SHA-256 簽章／一致性快照；年份讀取期間其他裝置仍可寫入，僅複查年度清單無法保證資料完全一致。此版不執行 AI 匯入或修改正式帳本；下一階段需要伺服端鎖與三方比對、XLSX 解析、獨立備份驗證。若需可靠全庫快照，請勿把此 JSON 當作經驗證備份。

部署：先在測試網址替換 index.html，Apps Script 不變。從「收支明細」點「匯出全部年度供 AI 整理」，留意瀏覽器是否阻擋多檔下載。
