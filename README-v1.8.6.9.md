# v1.8.6.9 — AI 智慧整理與人工審核

## 使用方式
1. 僅更新 index.html；不需更新 Apps Script。
2. AI 智慧整理主頁籤中使用同一次匯出的 BASELINE JSON 與 AI 建議 CSV，進行雲端三方比對。
3. 可於建議修改／待確認／維持／衝突清單中搜尋，選擇接受、保留、指定分類；審核草稿以 exportId 儲存瀏覽器 localStorage。
4. 下載決策 JSON 或實際修改 CSV，均**不**更新正式 Google Sheets；AI 發布、備份驗證、重入檢查尚未實作。
5. 收支明細的 Invoice CSV 匯入可選「原有規則」或「AI 離線建議」：後者下載 CSV 副本供外部 Codex／Claude 分類，**不會匯入、不會自動呼叫 AI**。原有規則模式保留原本寫入行為。

## 限制
- AI 建議清單只能使用現有分類；若有新分類，須先在正式帳本另行確認建立。
- 三方比對只做基本版本與不可變欄位檢查；尚未完成 AuditLog 欄位級追溯、備份、原子發布與失敗回復。
- 本機草稿不是正式備份；請另存決策 JSON。
- 請先以測試帳本驗證；不可直接將 AI 決策檔作為正式交易匯入。
