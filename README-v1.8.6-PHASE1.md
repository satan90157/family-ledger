# 家計簿 v1.8.6 — 第一階段開發版（尚未完成正式驗收）

## 已實作
- 收支明細清單中的歸屬及分類下拉選單；保留發票品項展開。
- 本機快速編輯草稿（依登入使用者、後端 URL 隔離），取消及重新整理恢復。
- 批次提交 `patchBatch`；後端各年度資料只讀取一次，索引 ID，將連續列合併寫入。
- 欄位級最後寫入者優先；只允許 `owner`、`category`；保留其餘交易 JSON 欄位。
- AuditLog 原有六欄保留，追加 ChangedFieldsJSON、OperationSource。
- 未完成草稿限制頁面切換、年度切換、分類/歸屬/月份篩選、登出；搜尋框停用直到保存或復原。
- 接收雲端成功回應後才移除對應草稿；其餘草稿保留。

## 部署安全
**請勿直接覆蓋正式版。** 先建立獨立測試 Spreadsheet、獨立 Apps Script Web App 與獨立 GitHub Pages 測試網址。

後端請把 `apps-script/TransactionPatch.gs` 與改過的 `apps-script/Code.gs` 一起部署。前端使用此資料夾的 `index.html`。

## 已測試
- `node --check` 前端腳本、Apps Script 新增模組語法檢查。
- 模擬 Apps Script Spreadsheet 進行不同欄位合併、同欄位最後寫入者生效、版本遞增、AuditLog、非法欄位及缺少交易的測試。

## 尚未完成，不應視為 v1.8.6 全部交付
- 尚未用真實 Google Apps Script／手機及電腦跨裝置驗收，也沒有在正式帳本執行寫入。
- 部分批次寫入失敗可能已改動前面的資料；完整交易性、失敗回復、持久發布鎖、操作冪等與發佈任務日誌屬後續安全發布模組。
- 尚未實作版本輕量查詢、自動週期偵測、詳細交易歷史介面。
- 尚未實作 AI XLSX 匯出/驗證/三方衝突處理、獨立不可覆蓋備份與 SHA-256 驗證。
- 既有 `delta` API 保留原樣；舊功能仍使用原有 `_rev` 衝突流程。
- 不同瀏覽器的草稿仍然各自本機保存，不能視為已雲端儲存。
